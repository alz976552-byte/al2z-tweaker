Утилита для настройки Windows с интерфейсом в стиле **«жидкое стекло»**. Это не игра и не драйвер: компактная панель, где собраны твики внешнего вида, производительности и приватности, мониторинг системы и управление установленными программами.

> ⚠️ **Внимание.** Программа меняет системные настройки и может удалять приложения. Перед использованием создайте точку восстановления и запускайте её **от имени администратора**. Используйте на свой страх и риск.

## Что умеет

- **Твики и пресеты** — внешний вид, производительность, приватность и системные параметры.
- **Мониторинг в реальном времени** — CPU, RAM, GPU и диск с анимированными графиками.
- **UWP-приложения** — список современных приложений из Store с возможностью удалить для текущего или для всех пользователей.
- **Программы** — список классических Win32-приложений и запуск их штатного деинсталлятора.
- **Обслуживание** — создание точки восстановления и перезапуск Проводника.
- **Инсталлер** — English NSIS installer, установка для всех пользователей с запросом прав администратора.

Интерфейс приложения на английском языке.

## Установка

1. Скачайте **`Al2zTweaker Setup 1.0.0.exe`** из раздела **Releases**.
2. Запустите файл и подтвердите запрос UAC.
3. После установки появятся:
   - ярлык **Al2zTweaker** на рабочем столе;
   - пункт в меню «Пуск»;
   - запись в «Установка и удаление программ» с корректным uninstaller-ом.

Для операций с системными настройками и удалением приложений запускайте установленную программу **от имени администратора**.

## Сборка из исходников

### Готовый сценарий

В Windows откройте терминал в папке проекта:

```powershell
.\build-installer.bat
```

Результат: `dist\Al2zTweaker Setup 1.0.0.exe`.

Сценарий сам справляется с зеркалами Electron, ограничениями npm postinstall и проблемой символических ссылок 7-Zip.

### Разработка

```powershell
npm install
npx electron .
```

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | Интерфейс на английском языке |
| `styles.css` | Тема «жидкое стекло», светлая и тёмная |
| `app.js` | Логика рендерера: пресеты, графики, списки UWP/Win32 |
| `main.js` | Главный процесс Electron и IPC |
| `preload.js` | Безопасный мост `electronAPI` |
| `utils.js` | серверная часть на PowerShell/WMI |
| `build-installer.bat` | Сборка инсталлера одним кликом |
| `fix-electron.ps1` | Восстановление бинарника Electron из кэша |
| `fix-7za.ps1` | Установка 7-Zip с поддержкой символических ссылок |
| `tools/7za-wrapper.cs` | Обёртка для 7-Zip |

## Безопасность

- Создавайте точку восстановления перед применением пресетов.
- Не удаляйте системные компоненты, назначение которых вам неизвестно.
- Права администратора нужны только для изменений уровня системы.
- Проект распространяется «как есть», без гарантий.
